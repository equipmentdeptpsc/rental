# P7.7 Implementation Backlog

## A. Must Have Before RBAC Enforcement

1. Canonical role repository/service with immutable protected-role identity.
2. Multi-role Users UI with atomic assignment/removal and no direct permissions.
3. Canonical Operator linkage and own-record scope enforcement.
4. Effective-permission display using the same authority source as enforcement.
5. Roles module: view, clone, create custom, compare, assigned users.
6. Permissions module with grouped modules/actions and deduplicated codes.
7. Authorization audit events for role assignment/removal, access reset, user status, role cloning, and custom-role changes.
8. Version-2 local comparison validation with zero unapproved privilege deltas.

## B. Should Have Before Production

1. Nine-section configuration registry with typed current value, description, last modified, modified by, and audit history.
2. Maker-checker controls for privilege escalation and sensitive configuration.
3. Custom-role validation preventing privilege escalation by cloning.
4. Search/filter/export for role comparisons and audit history, with redaction.
5. Session refresh and stale-authority invalidation after role changes.
6. Accessibility and end-to-end administration tests.

## C. Future Commercial ERP Enhancements

1. Time-bound and delegated role assignments.
2. Approval workflows for custom roles and sensitive role changes.
3. Role usage analytics, entitlement certification, and periodic access review.
4. Tenant-specific role templates with centrally governed permission taxonomy.
5. Segregation-of-duty rule engine and conflict simulation.
6. Configuration promotion workflows across environments.
